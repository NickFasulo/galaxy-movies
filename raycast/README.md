# Galaxy Movies

Raycast commands for [Galaxy Movies](https://www.galaxymovies.app)' free public feeds — no API key, no account.

- **Where to Watch** — resolve any movie or show to its US watch providers (subscription, free, ads, rent, buy) via `/api/ext/where`.
- **Streaming Changes** — today's arrivals, departures, and announced releases for 20 US streaming services via `/api/streaming-changes`.

Data is powered by Galaxy Movies (TMDB + Watchmode upstreams). Rate limit: 120 requests/hour per IP.
