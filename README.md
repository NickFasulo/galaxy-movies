# Galaxy Movies

### [Live Demo](https://galaxy-movies.vercel.app/)

A mobile-friendly application built with Next.js, React Query, and Chakra-UI that lets users browse trending movies, view movie details, and see previews.
The app includes infinite scrolling and the ability to view an AI-generated review using OpenAI.

Powered by [The Movie Database](https://www.themoviedb.org/)
